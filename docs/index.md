# Welcome to ADAM!

This online manual is designed to lead system administrators and users through the most common aspects of managing an ADAM database. This guide should also enable administrators to provide their users with competent user support.

The whole manual is also available as a single PDF, for offline reading or printing: [download the ADAM Instruction Manual](/adam-manual.pdf).

## Additional Support

Any issues that are not covered in this help documentation can be addressed to [help@adam.co.za](mailto:help@adam.co.za) for further information.

## Suggesting Changes

This is a living document and will be added to and improved over time. If you have any suggestions or wish to assist in improving the documentation, please see our [contributing guide](https://github.com/phinor/adam-docs/blob/main/CONTRIBUTING.md) — you do not need to be a programmer to help.
